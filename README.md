# Salim Slicer

Офлайн-слайсер для **Creality Ender 3 V3 SE** на чистом JavaScript. Работает прямо в браузере на компьютере и телефоне, без установки и сервера. Генерирует G-code под **стоковую прошивку Marlin** и проверяет его перед выдачей.

## Возможности

- 3D-просмотр модели и слоёв, поворот, масштаб, зеркало, авто-положение, тетрис-расстановка нескольких моделей
- Профили PLA / PETG / TPU, режимы Speed / Balanced / Quality / Min Weight
- Свои филаменты (ABS, ASA, карбон и др.) с учётом остатка катушки
- Поддержки, кайма, «мышиные ушки», юбка, настройка шва, рисунок заполнения (линии, сетка, треугольники)
- Профессиональные настройки: стенки, поток, первый слой, скорости, ускорения, откаты, Linear Advance K
- Режимы безопасности: Безопасный / Средний / Экстремальный, текущий режим всегда подсвечен рамкой по краю экрана
- Аудит G-code: границы стола, температуры, подача, объёмный поток, ускорения
- Оценка времени печати с калибровкой под экран принтера (M73)
- Проверка печатаемости модели и подсветка нависаний
- Тесты: температурная башня, ретракт, Linear Advance
- Цветовые темы, сохранение и загрузка проекта, автосохранение

## Запуск

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте `index.html` в браузере (Chrome, Edge, Firefox).
3. Нажмите «Открыть файл» и выберите STL, OBJ или 3MF.
4. Выберите пластик и режим, нажмите «Нарезать в G-code».
5. Скачайте файл и скопируйте на флешку для принтера.

Интернет не нужен: все библиотеки (three.js, JSZip, Tailwind, Font Awesome) лежат в папке проекта.

## Важно

- Проект рассчитан на Ender 3 V3 SE и стоковый Marlin. Для другого принтера проверьте профили и размеры стола в `config.js`.
- Первую печать нового профиля следите за первым слоем. Температуры и потоки подбирайте под свою катушку.
- Для PETG используйте «Безопасный» режим: на стоковом хотэнде реальный поток около 6–8 мм³/с.
- Режим «Экстремальный» увеличивает скорости и ускорения, возможны вибрации и недоэкструзия.
- Программа предоставляется «как есть». Вы печатаете на свой риск.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Интерфейс |
| `config.js` | Профили и состояние |
| `slicer-core.js` | Нарезка и генерация G-code |
| `marlin-safe.js` | Адаптер Marlin и аудит безопасности |
| `parsers.js` | Чтение STL / OBJ / 3MF |
| `viewport3d.js` | 3D-сцена |
| `ui.js` | Интерфейс, проекты, горячие клавиши |
| `features.js`, `expert-extra.js`, `filaments.js` | Настройки качества, эксперт-режим, свои филаменты |
| `calibration.js`, `printability.js`, `hints.js`, `themes.js` | Тесты, проверка модели, подсказки, темы |
