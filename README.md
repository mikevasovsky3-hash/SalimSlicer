# SalimSlicer
Салим Слайсер: офлайн-слайсер для Creality Ender 3 V3 SE на чистом JavaScript. Работает в браузере и на телефоне. 3D-просмотр, профили PLA/PETG/TPU, свои филаменты, поддержки, кайма, шов, проф. настройки и аудит G-code под стоковую прошивку Marlin: проверка границ стола, температур и потока.
